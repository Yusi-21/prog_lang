# ProgLang

Приложение на Flutter, которое показывает информацию о популярных языках программирования.

## О проекте

Это учебный проект, созданный в рамках практической работы по дисциплине «Проектирование и разработка кроссплатформенных мобильных приложений».

## Что внутри

- **StatelessWidget** — весь интерфейс статичен.
- **Виджеты:** Scaffold, AppBar, Column, Row, Center, Divider, SizedBox, Padding, Text, Icon.
- **Clean Architecture:** код разделён на слои (`presentation/models`, `presentation/screens`, `presentation/widgets`).

## Платформы

Приложение запускается на:
- Android
- Web
- Windows (Desktop)
